## 用户场景与测试 _(必填)_

### 用户故事 1 - 品牌故事 Hero 横幅 (优先级: P1)

访客进入 About 页面，首先看到一个富有情感冲击力的 Hero 横幅，传达品牌调性。横幅展示全宽氛围感背景图，标题 "Brand Story" 居中显示，下方配有 slogan "Bringing Happy to everyone. Let love run wild."。这一首屏印象奠定了品牌温暖、包容的基调。

**优先级理由**: Hero 横幅是访客看到的第一个视觉元素，在数秒内建立品牌情感认知。没有它，页面缺少核心品牌叙事入口。

**独立测试**: 导航至 `/about`，验证 Hero 横幅的背景图、标题、slogan 正确渲染，并在各设备上自适应布局。

**验收场景**:

1. **假设**访客在任意页面，**当**点击导航栏的 "About"，**则**跳转到 About 页面且 Hero 横幅作为首屏可见
2. **假设** About 页面加载完成，**当** Hero 横幅渲染，**则**展示全宽氛围背景图、居中标题 "Brand Story" 及下方 slogan "Bringing Happy to everyone. Let love run wild."
3. **假设**在移动端（≤640px）查看 About 页面，**当** Hero 渲染，**则**标题和 slogan 保持可读、居中、字号合适，无水平溢出
4. **假设**在平板端（640–1023px）查看 About 页面，**当** Hero 渲染，**则**布局在移动端和桌面端之间等比缩放
5. **假设** About 页面加载完成，**当** Hero 横幅渲染完毕，**则**背景图已优化，不造成布局偏移（CLS < 0.1）

### 用户故事 2 - 品牌宣言与数据统计区 (优先级: P1)

Hero 横幅下方，访客看到品牌宣言文案——"Connect, share, and explore in an open and free space."——紧接着是数据统计区，展示品牌的全球影响力。统计区展示两项核心指标：覆盖国家数（"12 Country"）和全球用户数（"1600000+ Global Users"）。当区域滚入视口时，数字从 0 以递增动画方式跳动到目标值，形成视觉冲击力。

**优先级理由**: 统计区提供社会证明和品牌可信度，数字递增动画是页面中最具记忆点的视觉时刻，对品牌认知和转化至关重要。

**独立测试**: 向下滚动越过 Hero 横幅，验证品牌宣言文案正确渲染，数字计数器在滚入视口时从 0 动画递增到目标值。

**验收场景**:

1. **假设** About 页面已加载，**当**访客向下滚动越过 Hero 横幅，**则**品牌宣言 "Connect, share, and explore in an open and free space." 居中显示
2. **假设**统计区位于视口以下，**当**访客滚动使其进入视口，**则**数字从 0 以平滑递增动画跳动到目标值（国家数 12，用户数 1600000+）
3. **假设**数字递增动画已完成，**当**访客滚走再滚回，**则**数字保持最终值不变（动画仅播放一次）
4. **假设**在移动端查看页面，**当**统计区渲染，**则**两项数据纵向堆叠或横向排列，间距合理、字号可读
5. **假设**统计数据从外部配置文件读取，**当**配置中的数值变更，**则**页面显示的数字和标签同步更新，无需修改代码

### 用户故事 3 - 分类 Tab 筛选与照片画廊 (优先级: P2)

统计区下方，访客看到一组水平 Tab 标签，包含四个分类："Social Contact"、"Share"、"Brand"、"Activity"。点击 Tab 可筛选下方的照片画廊，仅展示该分类的图片。画廊采用不规则瀑布流/网格布局，图片尺寸大小混搭，形成视觉层次感。每张照片卡片展示图片及可选标题（如 "My Aura stories"）。

**优先级理由**: Tab 画廊是页面的核心交互区域，展示品牌文化和社区内容。但仅有 Hero 和统计区时页面仍具备完整价值。

**独立测试**: 依次点击每个 Tab，验证画廊内容按分类筛选展示，切换时有平滑过渡动效。

**验收场景**:

1. **假设** About 页面已加载，**当**访客滚动到画廊区域，**则**默认激活 "Social Contact" Tab 并展示对应分类的照片
2. **假设**画廊区域可见，**当**访客点击 "Share" Tab，**则**激活状态指示器切换到 "Share"，画廊更新为 Share 分类的照片
3. **假设**访客点击不同的 Tab，**当**画廊内容切换，**则**过渡动效平滑（淡入淡出或滑动），300ms 内完成
4. **假设**画廊已显示，**当**照片渲染，**则**以不规则瀑布流/网格布局呈现，卡片尺寸混搭（高型、宽型、标准型），与设计稿一致
5. **假设**在移动端查看画廊，**当** Tab 渲染，**则** Tab 支持横向滑动或自然换行，画廊降级为单列或双列布局
6. **假设**某个 Tab 分类下没有配置内容，**当**访客点击该 Tab，**则**展示优雅的空状态提示（如 "More content coming soon"）

### 用户故事 4 - 加入社区 CTA 区块 (优先级: P2)

页面底部（全局 Footer 上方），访客看到一个暖色渐变背景的行动号召区块，标题为 "You can join Aura"，配有说明文案："Become a member of a supportive community that values equality and open dialogue."。下方展示社交媒体图标（Instagram、X/Twitter、Facebook、YouTube），作为可点击链接引导访客关注品牌社交账号。

**优先级理由**: CTA 区块是 About 页面的转化终点，将品牌叙事转化为实际互动。它支撑业务目标，但依赖上方区块先建立情感铺垫。

**独立测试**: 滚动到 About 页面底部，验证 CTA 标题、描述文案和社交媒体链接正确渲染，外链可正常跳转。

**验收场景**:

1. **假设** About 页面已加载，**当**访客滚动到底部，**则**在 Footer 上方显示渐变背景（粉色到深色调，与设计稿一致）的 CTA 区块
2. **假设** CTA 区块渲染完成，**当**区块可见，**则**标题 "You can join Aura" 和说明文案居中显示
3. **假设** CTA 区块渲染完成，**当**社交媒体图标显示，**则**每个图标（Instagram、X、Facebook、YouTube）链接到正确的外部 URL 并在新标签页打开
4. **假设**在移动端查看 CTA 区块，**当**渲染完成，**则**文案可读、图标可点击（最小触控区域 44×44px）、渐变背景适配良好

---

### 用户故事 5 - 滚动触发入场动画 (优先级: P3)

访客向下滚动 About 页面时，各区块（品牌宣言、统计区、画廊、CTA）在进入视口时播放淡入上移动画。这些动画提升页面的品质感，营造引导式叙事体验。

**优先级理由**: 动画属于体验层面的打磨，将页面从功能层提升到品质层，但不影响内容理解和页面可用性。没有动画页面依然完整可用。

**独立测试**: 缓慢滚动页面，验证每个区块在进入视口时播放入场动画，且动画仅播放一次、不遮挡内容。

**验收场景**:

1. **假设** About 页面已加载，**当**访客向下滚动，**则**各主要区块（品牌宣言、统计区、画廊、CTA）以淡入上移动效进入视口
2. **假设**某区块已完成入场动画，**当**访客滚走再滚回，**则**该区块保持可见状态，不重复动画
3. **假设**访客开启了系统的减少动效偏好，**当**区块进入视口，**则**动画被禁用，内容立即显示
4. **假设**任意区块正在执行动画，**当**动画播放，**则**保持 60fps 流畅运行，无卡顿或丢帧

### 边界情况

- Hero 背景图加载失败时怎么办？显示纯色兜底背景（深色/暖色调，匹配品牌色系），文字保持可见。
- 统计区数据值为 0 时怎么办？计数器正常渲染显示 "0"，无动画异常。
- 所有画廊分类均无内容时怎么办？Tab 区域和画廊整体隐藏，页面从统计区直接过渡到 CTA。
- CTA 中某个社交媒体链接未配置时怎么办？隐藏对应图标，不展示失效链接。
- 极慢网络下怎么办？内容渐进式加载——文字先出，图片以占位/模糊渐进方式加载。数字计数器等内容可见后才开始动画。
- 直接通过 URL（`/about`）访问页面时怎么办？页面完整渲染，包含正确的 SEO 元数据，导航栏 "About" 高亮显示。

**响应式与性能**

- **FR-023**: 所有区块必须（MUST）在移动端（≤640px）、平板端（640–1023px）、桌面端（≥1024px）三个断点下完全响应式，遵循项目的响应式内容宽度系统

- **FR-029**: 滚动动画必须（MUST）每个区块每次页面加载仅播放一次

### 关键实体

- **AboutHeroData**: 表示 Hero 横幅内容——背景图路径、标题文案、slogan 文案、兜底背景色
- **StatItem**: 表示单项统计数据——数值、后缀（如 "+"）、标签文案（如 "Country"、"Global Users"）
- **GalleryCategory**: 表示 Tab 分类——唯一标识符、显示标签（如 "Social Contact"、"Share"、"Brand"、"Activity"）
- **GalleryPhoto**: 表示画廊中的照片——图片路径、标题文案、所属分类标识符、卡片尺寸变体（tall/wide/standard）
- **CommunityCTA**: 表示 CTA 区块——标题文案、说明文案、社交媒体链接列表（平台名称、图标、URL）

## 假设条件

- Hero 背景图和画廊照片以静态资源形式提供（放置于 `/public/images/about/`），初期无需 CMS 或动态上传系统。
- 数字计数器的值（12 个国家、1600000+ 用户）配置为静态数据，从后端实时拉取分析数据不在本期范围内。
- 各 Tab 分类的画廊内容为预配置的静态数据，用户生成内容（UGC）的上传和审核不在本期范围内。
- 社交媒体 URL 为全局配置，可与 `001-global-shared-modules` 的 Footer 组件共享。
- 页面将以静态页面（SSG）形式实现，无服务端动态数据需求。
- 不规则瀑布流画廊布局采用预定义的尺寸模式（按照片配置），而非动态计算的瀑布流算法。
- 初期不要求国际化（i18n）支持，但文案内容集中在配置文件中，便于后续本地化。
