# Requirements Checklist: 内容管理页面

**Spec**: [../spec.md](../spec.md)

## 功能需求核查

- [ ] **FR-001**: `/admin/content` 路由可访问，仅桌面端布局（≥1024px）
- [ ] **FR-002**: 登录校验 — 显示账号密码表单，固定凭据 admin / aura1509
- [ ] **FR-003**: 登录状态 sessionStorage 管理（刷新保持，关闭标签页失效）
- [ ] **FR-004**: 表格展示所有文章：序号、标题、标签、图片路径、操作
- [ ] **FR-005**: 操作列包含「编辑」「预览」「删除」三个按钮
- [ ] **FR-006**: 搜索框支持按标题实时搜索过滤
- [ ] **FR-007**: 标签下拉筛选器支持按 NewsCategory 筛选
- [ ] **FR-008**: 分页功能，每页 10 条
- [ ] **FR-009**: 新增弹窗表单仅包含 4 个字段：图片（webp/png/jpg）、标签（三选一）、标题、内容
- [ ] **FR-010**: 系统自动生成衍生字段（id、slug、imageAlt、publishDate、summary、cardSize）
- [ ] **FR-011**: 表单验证：4 个必填字段 + 图片格式校验
- [ ] **FR-012**: 图片字段限制 webp/png/jpg 格式
- [ ] **FR-013**: 编辑弹窗预填充文章的 4 个字段
- [ ] **FR-014**: 删除确认对话框
- [ ] **FR-015**: 预览按钮在新标签页打开 `/news/{slug}`
- [ ] **FR-016**: 初始数据从 newsArticles 配置加载
- [ ] **FR-017**: 页面顶部显示文章总数统计
- [ ] **FR-018**: 删除后当前页为空时自动跳转上一页
- [ ] **FR-019**: 操作成功后显示提示
- [ ] **FR-020**: 不需要 SEO（管理页面）
- [ ] **FR-021**: 仅桌面端，不需要响应式

## 成功标准核查

- [ ] **SC-001**: 可完成登录、新增、编辑、删除、预览五项操作
- [ ] **SC-002**: 搜索筛选结果 200ms 内更新
- [ ] **SC-003**: 表单验证即时反馈（4 字段必填 + 图片格式）
- [ ] **SC-004**: 预览按钮在新标签页打开正确的文章详情页
- [ ] **SC-005**: `tsc --noEmit` 和 ESLint 无错误
- [ ] **SC-006**: 桌面端 (1280px+) 布局正确美观

## 用户故事核查

- [ ] **US0**: 管理员登录校验（固定凭据 admin/aura1509 + sessionStorage）
- [ ] **US1**: 文章列表展示 + 搜索 + 标签筛选 + 分页
- [ ] **US2**: 新增文章（4 字段弹窗表单 + 验证 + 衍生字段自动生成 + 保存）
- [ ] **US3**: 编辑文章（预填充 4 字段 + 修改 + 保存）
- [ ] **US4**: 删除文章（确认对话框 + 安全删除）
- [ ] **US5**: 预览文章（新标签页打开详情页）
